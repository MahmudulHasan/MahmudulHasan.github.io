# Mahmudul Hasan — Portfolio

Personal portfolio site: https://mahmudulhasan.github.io

Plain HTML/CSS/JS, tested with Playwright (desktop + mobile, axe-core accessibility checks) and deployed to GitHub Pages by GitHub Actions only when all tests pass.

```bash
npm install
npx playwright install chromium
npm test        # run the suite
npm start       # serve locally on http://localhost:4173
```
