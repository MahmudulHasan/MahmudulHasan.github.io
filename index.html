01. About Me

I'm a passionate Software Quality Assurance engineer based in Dhaka, Bangladesh. I build robust test automation frameworks covering end-to-end, REST API and mobile testing, and integrate them into CI/CD pipelines so every release is checked automatically.

I've worked with cross-functional, cross-timezone teams in Asia, Europe and the USA, owning the full QA process: requirement analysis, test design, execution, bug reporting, log monitoring and database validation. I also use AI tools to speed up both automated and manual QA work.

Outside work I enjoy reading books and blogs, travelling, and playing cricket, football, badminton, table tennis and FIFA.
